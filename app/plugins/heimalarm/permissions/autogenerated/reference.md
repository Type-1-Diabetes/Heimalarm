## Default Permission

Alle Heimalarm-Android-Befehle erlauben

#### This default permission set includes the following:

- `allow-status`
- `allow-open-battery-settings`
- `allow-open-notification-access`
- `allow-set-service`
- `allow-registerListener`
- `allow-remove-listener`
- `allow-install-apk`
- `allow-configure`
- `allow-pending-notifications`
- `allow-show-alarm`
- `allow-stop-alarm`
- `allow-play-sound`
- `allow-stop-sound`
- `allow-pick-sound`
- `allow-list-sounds`
- `allow-delete-sound`
- `allow-alarm-volume`
- `allow-set-alarm-volume`
- `allow-open-full-screen-settings`
